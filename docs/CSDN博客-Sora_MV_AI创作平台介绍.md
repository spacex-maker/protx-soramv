# AI2OBJ：一站式 AI 创作与提示词商城平台实践

> 本文基于笔者参与开发的 **AI2OBJ** 产品，从功能、业务与技术栈角度做一次梳理与分享，供对 AI 应用、多模态创作平台感兴趣的同学参考。

---

## 一、产品定位

**AI2OBJ** 是一个面向 C 端的 **AI 多模态创作平台**，集「文/图生图、文/图生视频、提示词交易、媒体工具、社区」于一体，目标是让用户在一个站点内完成：**创作 → 发布 → 变现 → 交流** 的完整闭环。

- **创作**：文生图、文生视频、图生图、图生视频，多种模型与工作流。
- **变现**：提示词商城（Prompt Market）支持创作者上架、售卖提示词，用 TOKEN 结算。
- **工具**：在线图片/视频/音频压缩，无需安装，即开即用。
- **社区**：频道、帖子、每日挑战、作品互动，形成内容与流量循环。

适合人群：内容创作者、设计师、短视频/音乐创作者，以及对 AI 生图/生视频有需求的个人与团队。

## 二、核心功能模块

### 2.1 首页

首页采用「模块化长页」结构，依次包含：

- **Hero 区**：主视觉 + 一句话价值主张，支持多语言与深色/浅色主题。
- **产品特性（Features）**：图文介绍核心能力（如 AI 视频生成、快速出片、多模型支持）。
- **技术展示（Technology）**：以 3D/动效等方式呈现技术感与品牌调性。
- **社区预览（Community）**：展示频道、热门内容、UGC 氛围。
- **提示词商城预览（Prompt Market）**：Bento 卡片布局，介绍「即装即用、创意变现、品质保障、探索实验室」等卖点，并引导进入工作区内的提示词商城。
- **定价（Pricing）**：套餐与权益说明（如基础版/专业版/团队版）。
- **媒体工具（Media Tools）**：图片压缩、视频压缩、音频压缩三个 Tab，直接嵌入工作区同款组件，首页即可试用。
- **CTA + Footer**：注册/登录入口与友情链接、条款等。

整体强调「所见即所得」：首页不仅能了解产品，还能轻度体验媒体工具与跳转到创作、商城、社区。

### 2.2 工作区（Workspace）

登录后进入工作区，左侧为统一导航：

- **创作（Create）**：入口到「文生图 / 文生视频 / 图生图 / 图生视频」等创作类型；内部支持多模型选择、参数配置、任务队列、历史记录、发布到社区、下载等。
- **提示词商城（Prompt Market）**：浏览/搜索/筛选（按类型、标签、排序）提示词商品；支持免费与 TOKEN 付费解锁；创作者可「发布作品」上架自己的提示词（含封面、描述、价格、预览图等）。
- **生成频道（Channels）**：与社区频道打通，在工作区内快速进入各垂直频道。
- **每日挑战（Daily Challenge）**：活动与任务入口。
- **媒体工具（Media Tools）**：与首页一致的图片/视频/音频压缩，在工作区中作为常驻工具。
- **产品日志 / 反馈 / 关于**：产品更新、用户反馈、关于我们。
- **立即充值 / 社区**：显眼按钮，引导充值 TOKEN 与进入社区。

技术实现上，工作区采用 **React + Ant Design + Styled Components**，子模块（如 Prompt Market、Create、MediaTools）按路由与组件拆分，便于维护与按需加载。

### 2.3 提示词商城（Prompt Market）

这是平台的差异化模块之一：

- **浏览**：卡片流式布局，展示封面、类型（文生图/文生视频/文生音乐）、价格（免费或 X TOKEN）、作者、收藏与销量。
- **筛选**：Tab 切换类型（全部推荐 / 文生图 / 文生视频 / 文生音乐）；标签筛选（热门标签来自后端推荐）；排序（最新上架 / 热门收藏 / 销量榜）。
- **搜索**：按关键词搜标题/风格/模型等。
- **详情**：弹窗/抽屉中查看描述、预览图、参数快照、作者信息；付费项需消耗 TOKEN 解锁完整提示词。
- **上架**：创作者从「我的创作」选择任务生成结果，填写标题、描述、封面、价格、是否隐藏提示词等，提交审核/上架。

业务上，提示词作为「数字商品」以 TOKEN 结算，平台可抽成或制定规则，形成创作者经济闭环。前端与 **productx-backend 的 core 模组** 对接列表、详情、下单、订单等接口。

### 2.4 创作（Create）

- **文生图（Text-to-Image）**：输入提示词，选择模型与参数，生成图片；支持历史记录、任务详情、发布到社区、下载。
- **文生视频（Text-to-Video）**：文本描述生成短视频，多模型与分辨率选项。
- **图生图（Image-to-Image）**：上传参考图，生成变体或风格化结果。
- **图生视频（Image-to-Video）**：以图驱动视频生成。
- **工作流（Workflow）**：节点式编排（如 Sora、Runway、Kling、Luma 等节点），适合进阶用户。

共同点：模型选择、参数配置、任务队列、结果预览与下载、与社区/商城的联动（如「发布到社区」「从作品上架到提示词商城」）。

### 2.5 媒体工具（Media Tools）

- **图片压缩**：上传图片，设置质量/尺寸等，批量压缩，对比预览，下载。
- **视频压缩**：自定义分辨率、码率，多格式支持，压缩前后对比。
- **音频压缩**：优化文件大小，保持音质，支持 MP3、AAC 等。

组件在首页与工作区复用，技术栈与主站一致（React + Ant Design），便于统一体验与维护。

### 2.6 社区（Community）

- **频道（Channels）**：按主题/类型划分频道，列表与详情页展示帖子数与介绍。
- **帖子（Post）**：标题、正文、图片/视频、作者、点赞/收藏/评论、提示词展示与复制、Remix 等。
- **每日挑战（Daily Challenge）**：活动页、规则、投稿与作品墙、奖励说明。
- **探索 / 热门**：发现优质 UGC，增强留存与二次传播。

社区与工作区、提示词商城打通：创作结果可一键发布到社区；社区内容可反向引导用户使用创作与商城。

### 2.7 账户与支付

- **登录/注册**：支持邮箱、验证码及第三方登录（如 Google）。
- **个人中心/设置**：资料、安全、隐私偏好、通知等。
- **钱包/充值**：TOKEN 余额、充值套餐、支付渠道（与后端及支付网关对接）。
- **订单/订阅**：消费记录、订阅管理（若有会员体系）。

## 三、技术栈概览

| 层级     | 技术选型 |
|----------|----------|
| 前端     | React、Ant Design、Styled Components、Framer Motion、react-intl |
| 请求     | Axios、与 productx-backend 的 core 模组 REST API 对接 |
| 存储/CDN | 腾讯云 COS，图片展示统一加万象 CI 压缩参数（格式/质量/缩略图） |
| 后端     | Java + Spring Boot + Maven（core/manage 模组） |
| 数据库   | MySQL |
| 国际化   | react-intl，多语言 locale 文件（中/英/日/韩/西/法/德/意/葡/俄/阿等） |
| 部署     | 前端可部署至 Cloudflare Pages 等；后端独立部署 |

**开发规范示例**：  
- 所有展示用图片 URL 需加腾讯云万象压缩后缀（如 `?imageMogr2/format/webp/quality/80/thumbnail/xxx`），以兼顾加载速度与带宽。  
- 文案统一走 react-intl，避免硬编码，便于多语言与后续运营修改。

## 四、业务闭环简述

1. **拉新**：首页展示能力与案例 → 注册/登录。  
2. **留存**：工作区内创作、使用媒体工具、浏览提示词商城与社区，形成习惯。  
3. **变现**：  
   - 用户：充值 TOKEN，购买提示词、使用高级模型或权益。  
   - 创作者：在提示词商城上架作品获得 TOKEN，或通过社区曝光带来间接收益。  
4. **传播**：社区内容、每日挑战、优质提示词商品在站内与站外分享，带来新用户与复访。

## 五、小结

**AI2OBJ** 把「AI 多模态创作 + 提示词交易 + 媒体工具 + 社区」整合在一个 C 端产品里，既满足「用 AI 出图/出视频」的需求，又通过提示词商城和社区构建创作者生态与平台收入。技术上前端 React 全家桶、后端 Java Spring Boot、腾讯云 COS 与统一国际化/规范，适合作为「全栈 AI 应用」的参考案例。
